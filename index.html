고민의 배경

한 달 목표를 날짜별로 나누는 일이 담당자의 감에 의존해, 배분 근거를 설명하거나 오차 원인을 추적할 수 없었습니다.

접근 방식

이 숫자는 예측이 아니라 한 달 운영의 기준선이라고 봤습니다. 사업의 기본 체력 대비 매출을 크게 움직이는 행사만 반영하면 되고, 같은 브랜드의 같은 유형 행사는 상승 폭이 비슷하다는 점에 착안해 행사 일정을 숫자로 바꿨습니다.

실행

  • 사업의 기본 체력(평시 매출 수준)을 기준선으로 설정
  • 기본 체력 대비 매출을 크게 움직이는 행사를 정의하고 전사 행사 / 브랜드 행사로 나눠 관리
  • 브랜드 × 행사 유형별 매출 상승 폭을 과거 실적에서 산출해, 프로모션 일정을 일자별 매출 상승분으로 변환
  • 리더가 특정 날짜를 조정하면 나머지 날이 비율대로 움직이고 팀별 월 합계는 고정되는 구조

결과

  • 2024년부터 매월 운영, 배분값이 전사 일 목표로 사용
  • 영업팀의 일별 진척 점검과 남은 기간 전략 수립 기준
매주 월요일차이 분석과 전략 수정미팅당 보고 30분 → 5분

고민의 배경

매입·재고·할인·행사·공급사 지원금이 동시에 움직여 예측 정확도에는 한계가 있었고, 원인 파악은 영업팀 자체 보고에 기대고 있었습니다.

접근 방식

예측의 목적을 정확도에서 원인 규명과 의사결정 속도로 바꿨습니다. "어디서 얼마가 비는지"부터 합의되도록, 제 자료가 회의의 기준이 되게 만드는 데 집중했습니다.

실행

  • 목표 대비 차이를 상품마진 · 공급사 지원금 · 재고요소 세 갈래로 분해
  • 이미 실현된 차이와 가정 변경으로 생긴 차이를 분리하고, 팀·항목별로 차이가 큰 곳을 표시
  • 영업팀은 최소한만 입력하면 상세 예측이 나오는 입력 구조
  • 메워야 할 차이의 크기와 방향(매출 또는 마진)을 제시하면, 영업팀이 가격·쿠폰·노출 조정으로 대응 전략을 결정

접근 방식

평가는 납득할 수 있는 기준이 먼저라고 봤습니다. 원천 수치는 그대로 두고 왜곡이 생기는 지점에만 보정 원칙을 두었고, 점수에서 그치지 않고 보완할 점까지 보이도록 리포트를 설계했습니다.

실행

  • 월별 담당 이력을 따로 보관해 실적이 그달 담당자에게 귀속되는 구조
  • 산식 원칙: 달성률 상한 없음, 실적이 있는 달의 목표만 누적, 목표가 없는 브랜드는 달성률 중립 처리
  • 주문 목표는 거래액 목표에 1분기 평균 객단가를 적용해 산출
  • 목표·실적 조합별 왜곡 사례를 유형화해 대체 평가 원칙과 지표 개선안을 경영진에 제안
  • 원천 데이터 5종 통합, 담당자 매칭·브랜드 정합성 점검 시트와 월별 운영 가이드 작성
  • 담당자별 진단 리포트: 종합 점수, 팀 내 순위, 강점, 보완 항목, 단일 브랜드 의존도

물류부서에서는 "객단가를 올려 달라"는 요청이 꾸준히 왔지만, 객단가는 명절 선물세트나 생활 카테고리 브랜드의 비중만으로도 움직이는 지표라 무엇을 움직여야 오르는지부터 찾아야 했습니다.

먼저 행사 때 단가는 10% 안팎으로 움직여도 주문당 구매수량은 거의 변하지 않는다는 점을 확인했고, 이 진단이 ④ 기획전의 출발점이 됐습니다.

다만 기존 월간 보고는 가격대별 비중만 나열해서, 원인과 해당 브랜드를 매번 수작업으로 찾아야 했습니다.

접근 방식

객단가를 상품 단가와 주문당 구매수량의 곱으로 정의해 가격·수량 요인을 나누고, 같은 방식으로 브랜드와 상품까지 내려가 "누가 움직였나"를 찾도록 설계했습니다.

실행

  • 로그 분해로 변동률을 단가·수량 기여분으로 배분(합계 100%), 단계별 합계 검증
  • 상승 원인을 단가형 · 수량형 · 브랜드 비중형으로 자동 분류하고 유형별 기여 상위 브랜드 추천
  • 상품별 변동 요인(구매수량 증가, 판매단가 상승, 비중 변화, 신규 판매)을 기준값으로 자동 판정하고 근거 수치가 붙은 코멘트 생성
  • 1P 전 브랜드·상품코드 약 2만 개(원천 약 35만 행) 대상, 브랜드를 고르면 요약·분해·기여 상위 30개 상품 자동 갱신
  • 매크로 없이 수식으로만 구성해 기준월만 바꾸면 매월 갱신
